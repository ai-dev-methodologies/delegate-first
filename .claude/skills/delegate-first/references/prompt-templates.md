# Prompt Templates

## Contents
- Template 1: Read-only investigation
- Template 2: Implementation / edit
- Worked examples (generic — replace with your own project's cases)

## Template 1 — 조사용 (read-only)

```
역할: <한 줄 — 예: "결제 모듈의 재시도 로직 현황을 조사하는 read-only 조사 에이전트">

작업 디렉터리: <절대경로>
경계: <수정 금지 범위 — 예: "docs/decisions/ 읽기만, 쓰기 금지. 시스템 설정 변경 명령 금지(tccutil·csrutil·systemsetup 등)">

조사 범위: <구체적 질문·파일·경로>
증거 요구: 없다고 결론 내릴 경우 어디까지 찾아봤는지(탐색한 경로·명령) 명시할 것 — "없음"과 "안 찾아봄"을 구분

완료 기준:
- [ ] <검증 가능한 결과물 1>
- [ ] <검증 가능한 결과물 2>
- [ ] 한계·모르는 것 명시

출력 형식: <보고서 구조 — 예: 결론 3줄 + 근거 원문 인용 + 파일:라인 참조>
```

**예시** (중립 예시 — 설치 프로젝트의 실제 사례로 교체해 쓸 것):

```
역할: 의존성 메이저 업그레이드의 선행조건을 확인하는 read-only 조사 에이전트

작업 디렉터리: <레포 절대경로>
경계: src/, docs/ 읽기만. 파일 수정·git 조작 금지.

조사 범위:
- 현재 설치 버전(락파일 기준)과 목표 버전의 차이
- 업그레이드 가이드가 요구하는 선행조건 항목
- breaking change 영향 지점(호출부) 목록
- 선행조건 항목별 충족/미충족 판정

증거 요구: 버전·커밋 SHA는 실제 파일(매니페스트, 락파일, .git 등)에서 확인한 원문을 인용. 확인 못한 항목은 "미확인"으로 명시.

완료 기준:
- [ ] 선행조건 표에 충족/미충족 표시
- [ ] 각 판정에 근거 파일 경로 인용
- [ ] 업그레이드 착수 가능 여부 결론

출력 형식: 표(선행조건 | 상태 | 근거) + 결론 3줄
```

## Template 2 — 구현·편집용

```
역할: <한 줄>

작업 디렉터리: <절대경로, worktree 경로 명시>
경계: <수정 가능 범위 / 수정 금지 범위 — 예: "R1/R2 기존 코드·스키마·마이그레이션 수정 금지">
시스템 설정 명령 금지: 진단·수리 목적이라도 시스템 명령(tccutil, csrutil, Docker 컨테이너 생성/삭제 등) 실행 금지 — 환경 오류 시 중단·보고만.

목표: <1~4개 번호 목록, 구체 산출물>
안전 경계: <위반 시 즉시 중단 조건 — 예: "403/429 즉시 중단(재시도 없음)">

완료 기준 (REPORT.md/응답에 증거 원문):
- [ ] <산출물 1>
- [ ] <산출물 2>
- [ ] 한계·모르는 것 명시 (아는 척 금지)

출력 형식: <파일 경로 + 커밋 여부 + 보고 형식>
```

**예시** (중립 예시 — 설치 프로젝트의 실제 사례로 교체해 쓸 것):

```
역할: 외부 검색 API 2종으로 표본 등재 여부를 확인해 매칭표 완성

작업 디렉터리: <레포/worktree 절대경로> (브랜치 feat/<작업명>)
경계: 기존 스키마·마이그레이션·인접 모듈 수정 금지. 산출물은 <산출물 디렉터리>에만 둔다.
시스템 설정 명령 금지: 컨테이너·환경 변경 금지. 환경 오류 시 중단·보고만.

목표:
1. API A로 표본 100건 등재 여부 확인
2. API B로 동일 표본 교차 확인
3. matching-table.csv 갱신 + coverage-analysis.md 작성

안전 경계: 403/429 즉시 중단(재시도 없음), 호출 예산 API별 ≤500, 개인정보 취득 금지.

완료 기준 (REPORT.md에 증거 원문):
- [ ] matching-table.csv 100행 전부 '등재/미등재/보류' 채워짐 ('미확인' 0)
- [ ] 기준축 후보별 커버리지 표 + 후속 결정 권고
- [ ] API 호출량·한도 기록
- [ ] 한계·모르는 것 명시

출력 형식: REPORT.md + PR (git 커밋·push·PR 주체는 프로젝트 규약에 따름 — 위임 프롬프트에 명시)
```
